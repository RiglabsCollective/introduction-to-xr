# Introduction to Extended Reality

Course material for the 25-hour Faculty Development Programme **Introduction to Extended Reality**.

## Contents

- [`lens-studio/`](lens-studio/) – hands-on Snap Lens Studio lenses. Each lens has a step-by-step guide, and a shared `assets` folder gives you everything you need to build your own version. New to it? Start with [Getting started with Lens Studio](lens-studio/GETTING-STARTED.md).
- [`Unity/`](Unity/) – hands-on Unity projects: five AR projects and one VR demo. Each has a step-by-step guide for the computer, Android and iPhone. New to it? Start with [Getting started with Unity](Unity/GETTING-STARTED.md).

## How to use this repo

1. Click **Code → Download ZIP** (or clone with Git).
2. Do the **Getting started** guide for the tool you will use. It covers the download, your account and your code editor.
3. Open `lens-studio/` or `Unity/`, pick a project and open its `README.md`.
4. Use the files in that folder's `assets/` while you follow the steps.
