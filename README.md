# Introduction to Extended Reality

Course material for the 25-hour Faculty Development Programme **Introduction to Extended Reality**.

## Contents

- [`lens-studio/`](lens-studio/) – hands-on Snap Lens Studio lenses. Each lens has a step-by-step guide, and a shared `assets` folder gives you everything you need to build your own version.

## How to use this repo

1. Click **Code → Download ZIP** (or clone with Git).
2. Open `lens-studio/`, pick a lens and open its `GUIDE.md`.
3. Use the files in `lens-studio/assets/` while you follow the steps.
